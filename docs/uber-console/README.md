# لقطات كونسول أوبر — لتأكيد تصميم الربط

> **الغرض:** أحتاج مخرجات أوبر الفعلية عشان أأكّد التصميم النهائي قبل البناء. حطّ اللي جرّبته بالكونسول هون، وقول لي «جاهز».

## شو أحتاج بالضبط

### 1. `request.js` — الكود اللي شغّلته
انسخ كود الكونسول اللي جرّبته (مسح المعلومات الحسّاسة إن وجدت — مش لازم كوكيز حقيقية).

### 2. `response.json` — الردّ اللي طلع
الصق الـJSON اللي رجع. **مهم جداً** أشوف فيه:

- [ ] **حقل الاسم:** كامل (`"Mahmoud Zedya"`) ولا مختصر (`"Mahmoud Z."`)؟ منفصل firstName/lastName؟
- [ ] **الـdriverUUID:** اسم الحقل بالضبط + شكل القيمة
- [ ] **إيميل السائق:** موجود بالردّ ولا لأ؟
- [ ] **جوال السائق:** موجود ولا لأ؟
- [ ] **تفاصيل الرحلة:** العنوان، الأجرة، الراكب — شو بيرجع بالضبط

### 3. (لو جرّبت) endpoint معلومات السائق نفسه
لو في endpoint يجيب بيانات **حساب السائق** (مش تيار العروض) — زي `/me` أو profile —
حطّه بملف منفصل: `driver-me-request.js` + `driver-me-response.json`.
هذا الأهم، لأنه بيأكّد إذا الـUUID لحاله بيكفي للربط، أو محتاجين إيميل/جوال كمان.

## ملاحظات
- **امسح أي كوكيز أو توكن حقيقي** قبل ما تحطّ الكود — مش محتاجهم، ومش آمن يتخزّنوا.
- لو الردّ طويل، لا تقصّه — الحقول الكاملة هي اللي بتفيدني.
- خلّص؟ قول لي «جاهز» وأبدأ الخطة.
