## 1. المبادئ المشتركة

- **الألماني افتراضي**، مع de/en/ar في كل مكان، و**RTL للعربية** (`RTL_LOCALES = ["ar"]` تضبط `dir="rtl"` + `lang`).
- **الأرقام لاتينية دائماً** — المال/المسافة/التاريخ يُعرض بأرقام غربية حتى في العربية (`latnLocale()` / `toLatinDigits()` بالفرونت؛ إجبار `"en-DE"` بتطبيق السائق).
- **لا ألوان مثبّتة (hex)** — استخدم توكنات دلالية فقط.

## 2. اللوحة (Next.js · Tailwind v4)

- **Tailwind v4 «CSS-first»** بلا `tailwind.config.js`. التوكنات الدلالية متغيّرات CSS في `globals.css` على `:root` (فاتح) و`.dark` (داكن)، مكشوفة عبر `@theme inline` كأدوات (`bg-surface`, `text-ink`, `border-line`، ونغمات الحالة `success/danger/warning/info/accent`).
- **الدارك مود صنفي** (`@custom-variant dark`) — يُبدَّل بإضافة صنف `.dark` على الجذر (يُحفظ في localStorage، سكربت pre-paint يمنع الوميض)، و`color-scheme` يتبع الثيم فتتبعه ضوابط المتصفّح الأصلية.
- **اللون الأساسي:** الإمرلد (`--primary: #059669` فاتح / `#10b981` داكن) لمسة العلامة.
- **الخطوط:** **Manrope** للّاتيني (`--font-manrope`) مع الإبقاء على **Tajawal** للعربي (إصلاح كسر الخط العربي).
- **مكوّنات:** خريطة Leaflet للسواقين الأحياء + مسار الرحلة؛ Firebase web push للجرس.

## 3. تطبيق السائق (Expo)

- **الثيم** عبر `useColors()` (`driver-app/src/lib/theme.ts`) يرجّع لوحة فاتح/داكن — نظام أحادي اللون (أسود/أبيض/رمادي) مع الإمرلد كلمسة ثانوية للحالات النشِطة/القبول، وألوان دلالية لحالات دورة حياة العرض:
  - `pending` كهرماني، `accepted`/`completed` إمرلد خافت، `started` محايد، `rejected` رمادي، `canceled` أحمر.
- **الخطوط:** **Manrope** (أرقام/لاتيني) + **Tajawal** (عربي)، محمّلة عبر splash-gate فالإطار الأول لا يومض.
- **فاتح/داكن** يطابق اللوحة (يتبع `useColorScheme` مع تجاوز اختياري).
- **حالات الشاشات** (فاتح/داكن/RTL/فارغ/تحميل/إذن مرفوض/اشتراك موقوف): مرجعية في `driver-app/screens/*.png` و`driver-app/README.md`.

## 4. عناصر واجهة مرتبطة بقواعد المنتج

- **بطاقة العرض** تُظهر دائماً: السعر + شارة **جودة €** (`€`/`€€`/`€€€`) + الاستلام → الوجهة + المسافة و€/كم + **عدّاد نافذة القبول** (SVG دائري).
- **الرحلة متعددة المحطات** تعرض عناوين لكل محطة + كم لكل leg (`stops[]`) على اللوحة والتطبيق.
- **حالات دورة الحياة** تُترجم (مثال ألماني: Offen / Angenommen / Auf Fahrt / Fertig / Abgelehnt / Storniert).
