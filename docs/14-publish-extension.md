# نشر إضافة Reidey (Chrome Web Store)

دليل خطوة بخطوة لنشر إضافة المتصفح (MV3) وتوزيعها للعملاء مع تحديث تلقائي.

> الإضافة تلتقط جلسة أوبر (بيانات حسّاسة) — فالنشر لازم يكون **Unlisted** (توزيع مُتحكّم) مع **سياسة خصوصية**.

---

## 1) قبل النشر — تجهيز الحزمة

الملفات في `extension/`. تأكد من `manifest.json`:
- **`version`**: ارفعه عند كل إصدار (مثلاً `1.14.0` → `1.15.0`) — هذا ما يشغّل التحديث التلقائي.
- **`name` / `description`**: واضحين بالألماني/الإنجليزي.
- **`icons`** (16/32/48/128) موجودة ✅.
- **`host_permissions`**: محصورة بأوبر + `https://reidey.de/*` فقط ✅ (لا توسّعها).

**اعمل zip للنشر (بدون ملفات مصدر زائدة):**
```bash
cd extension
zip -r ../reidey-extension-v$(grep '"version"' manifest.json | grep -oE '[0-9.]+').zip . \
  -x "*.git*" -x "*.DS_Store"
```
> تأكد إن الـzip يحتوي `manifest.json` بالجذر مباشرة (مش داخل مجلد فرعي).

**أصول المتجر المطلوبة:**
- أيقونة 128×128 PNG (عندك `extension/icons/icon-128.png`).
- 1–5 لقطات شاشة **1280×800** أو **640×400** (مثلاً: صفحة "ربط أوبر" باللوحة + توست "تم الربط").
- وصف مختصر (سطر) + وصف مفصّل (شو بتعمل الإضافة).
- **رابط سياسة خصوصية (إلزامي):** استخدم صفحة الخصوصية على الموقع `https://reidey.de/datenschutz` (أو صفحة مخصّصة تشرح: نلتقط جلسة أوبر لمزامنة الأسطول، مشفّرة، لا تُشارك).

---

## 2) حساب المطوّر والرفع

1. سجّل في [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole) — **رسوم لمرة واحدة $5**. (للنشر باسم الشركة استعمل حساب Google مؤسسي.)
2. **New item** → ارفع الـzip.
3. عبّي الـlisting: الاسم، الوصف، اللقطات، الأيقونة، الفئة (Productivity)، اللغة.
4. **Privacy practices**: اشرح استخدام `cookies`/`host_permissions` + الصق رابط سياسة الخصوصية. (Google بيسأل عن كل صلاحية — برّر: `cookies` لمزامنة جلسة أوبر، `scripting` للالتقاط، `storage` لتخزين التوكن.)
5. **Visibility**: اختر **Unlisted** (يشتغل بالرابط فقط، ما يظهر بالبحث — الأنسب لإضافة حسّاسة).
6. **Submit for review**.

**المراجعة:** عادة ساعات–أيام. إضافات تلمس مواقع طرف ثالث (أوبر) قد تُراجَع أدقّ — كن مستعد تشرح الغرض (أداة إدارة أسطول للمالك نفسه).

---

## 3) الرؤية (Visibility) — مهم

| الخيار | متى |
|---|---|
| **Unlisted** ✅ موصى | يشتغل بالرابط فقط، ما يظهر بالبحث. الأنسب لتوزيع مُتحكّم للعملاء. |
| Public | يظهر بالبحث للجميع (غير مناسب لإضافة حسّاسة). |
| Private (Group) | لمستخدمي مؤسستك فقط عبر Google Workspace. |

---

## 4) التحديث التلقائي (بدون تدخّل المستخدم)

- Chrome **يحدّث تلقائياً** من المتجر خلال ساعات — العميل ما بيعمل شي.
- **كل إصدار:** ارفع `version` في `manifest.json` → اعمل zip جديد → ارفعه على نفس الـitem → Submit. المستخدمون ياخذوا التحديث تلقائياً.

---

## 5) تسهيل التثبيت للعملاء (UX)

- **زر "أضف إلى Chrome"** برابط المتجر مباشرة من صفحة "ربط أوبر" + الأون-بوردينغ (نقرة واحدة).
- بعد التثبيت: العميل يفتح "ربط أوبر" → **افتح أوبر واربط** → يسجّل دخول supplier.uber.com → الإضافة تلتقط الجلسة تلقائياً.
- الإضافة تبعت نسختها مع كل مزامنة؛ اللوحة تعرض بانر **"حدّث الإضافة"** لو كانت قديمة.

---

## 6) بديل: Firefox (اختياري)

`manifest.json` فيه `browser_specific_settings.gecko` أصلاً. للنشر على Firefox:
1. [addons.mozilla.org](https://addons.mozilla.org/developers/) → Submit a New Add-on.
2. ارفع الـzip → اختر **"On your own"** (self-distribution) للتوزيع المُتحكّم، أو "On this site" (listed).
3. Mozilla توقّع الإضافة (إلزامي للتثبيت).
